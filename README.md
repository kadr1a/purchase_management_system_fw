# Система управления закупками

## Назначение проекта

Веб-приложение предназначено для просмотра данных системы управления закупками организации. Предметная область включает каталог товаров, поставщиков, заявки на закупку и заказы поставщикам.

Проект является продолжением консольного приложения из ПР3. В ПР5 к существующей объектной модели добавлен веб-слой на Django: HTTP-обработка запросов, URL-маршрутизация, view-функции и HTML-страницы.

## Предметная область и объектная модель

В проекте используются четыре класса предметной области:

- **Product** (`models/product.py`) — товар: `id`, `name`, `price`, `description`.
- **Supplier** (`models/supplier.py`) — поставщик: `id`, `name`, `contact`, `rating`.
- **Application** (`models/application.py`) — заявка на закупку: `id`, `purpose`, `product_items`, `status`. Заявка содержит ссылки на товары и их количество.
- **PurchaseOrder** (`models/purchase_order.py`) — заказ: `id`, `application`, `supplier`, `total`, `status`. Заказ связан с заявкой и поставщиком.

Связи между объектами сохранены: заявка содержит товары, а заказ ссылается на заявку и поставщика.

## Возможности веб-интерфейса ПР5

- главная страница с навигацией по разделам;
- просмотр списка товаров и карточки отдельного товара;
- просмотр списка поставщиков и карточки поставщика;
- просмотр заявок, их состава, количества товаров и общей суммы;
- просмотр заказов, связанных заявок и поставщиков;
- динамические URL с идентификаторами объектов;
- обработка отсутствующих объектов и неизвестных URL с HTTP-статусом 404;
- адаптивное оформление с Bootstrap 5.3 и собственным CSS.

На этапе ПР5 веб-интерфейс предназначен для просмотра данных. Создание, изменение и удаление сущностей через веб-формы пока не реализованы. Эти операции остаются доступны в консольной версии.

## URL веб-приложения

| URL | Назначение |
|---|---|
| `/` | Главная страница |
| `/products/` | Список товаров |
| `/products/<product_id>/` | Карточка товара |
| `/suppliers/` | Список поставщиков |
| `/suppliers/<supplier_id>/` | Карточка поставщика |
| `/applications/` | Список заявок |
| `/applications/<application_id>/` | Состав и сумма заявки |
| `/orders/` | Список заказов |
| `/orders/<order_id>/` | Подробная информация о заказе |

Маршруты верхнего уровня находятся в `procurement/urls.py`, маршруты отдельных разделов — в `urls.py` соответствующих приложений.

## Хранение данных

В ПР5 сохраняется JSON-хранилище, разработанное в ПР3. Данные читаются функцией `storage.load_data()` из файлов:

- `data/products.json`;
- `data/suppliers.json`;
- `data/applications.json`;
- `data/orders.json`.

Модуль `web_utils.py` предоставляет view-функциям единый способ загрузки данных. При этом `storage.py` восстанавливает связи между товарами, заявками, поставщиками и заказами.

**Django ORM в ПР5 не используется.** Файлы `models.py` внутри Django-приложений оставлены без моделей. Классы предметной области продолжают находиться в исходном пакете `models/`. Перенос на Django ORM относится к следующим этапам практических работ.

## Установка и запуск

Требуется Python 3.10 или новее.

Создание виртуального окружения:

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
```

macOS/Linux:

```bash
source .venv/bin/activate
```

Установка зависимостей:

```bash
pip install -r requirements.txt
```

Запуск консольной версии ПР3:

```bash
python main.py
```

Запуск веб-приложения ПР5:

```bash
python manage.py runserver
```

Откройте в браузере адрес http://127.0.0.1:8000/.

## Проверка проекта

Проверка системных настроек Django:

```bash
python manage.py check
```

Запуск автоматических тестов:

```bash
pytest -v
```

Проверка качества кода:

```bash
flake8 .
```

Для проверки собственной страницы 404 можно временно установить `DEBUG = False` в `procurement/settings.py` и открыть несуществующий адрес. После проверки рекомендуется вернуть `DEBUG = True` для локальной разработки.

## Git

Работа продолжается в существующем репозитории ПР3. Для фиксации изменений ПР5 используются коммиты с префиксом `PR5:`, например:

```bash
git add .
git commit -m "PR5: add Django web interface"
```

## Границы реализации ПР5

В этой версии реализованы структура Django-проекта и приложений, маршрутизация, view-функции, HTML/CSS/Bootstrap, отображение данных из JSON и обработка 404. Формы, аутентификация, Django ORM и перенос постоянного хранения на базу данных не входят в текущий этап.
