# Система управления закупками

## Назначение

Консольное приложение для учёта товаров, поставщиков, заявок на закупку и заказов. Версия ПР2 расширяет начальный сценарий ПР1: данные обрабатываются в коллекциях Python и сохраняются в JSON-файлах.

## Целевая аудитория

Сотрудники организации, которые формируют заявки на закупку, согласуют их и оформляют заказы поставщикам.

## Предметная область

Организация и сопровождение закупочной деятельности: ведение справочника товаров и поставщиков, формирование заявок, согласование закупок и оформление заказов.

## Основные сущности

- **Product** — товар с названием, ценой и описанием.
- **Supplier** — поставщик с контактными данными и рейтингом.
- **Application** — заявка с назначением, списком товаров и статусом.
- **PurchaseOrder** — заказ, связанный с заявкой и поставщиком, с перечнем товаров, итоговой суммой и статусом.

На ПР2 сущности представлены словарями, а наборы записей хранятся в списках. Классы и объекты не используются.

## Реализованные функции

- добавление, поиск, фильтрация по цене и сортировка товаров;
- добавление, поиск и сортировка поставщиков по рейтингу;
- создание заявки и добавление в неё товаров с количеством;
- расчёт общей стоимости заявки;
- согласование только непустой заявки;
- создание заказа только на основании согласованной заявки;
- отмена оформленного заказа;
- загрузка данных при запуске и сохранение изменений в JSON;
- обработка некорректного ввода и ошибок операций.

## Формат хранения данных

Данные хранятся в четырёх JSON-файлах в каталоге `data`. Каждый файл содержит JSON-массив словарей. Связи между сущностями представлены идентификаторами: в заявке товары сохраняются в `product_items` с `product_id`, а в заказе используются `application_id` и `supplier_id`. При создании заказа данные товаров копируются из согласованной заявки.

## Установка и запуск

Требуется Python 3.10 или новее.

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
```

macOS/Linux:

```bash
source .venv/bin/activate
```

Установка зависимостей:

```bash
pip install -r requirements.txt
```

Запуск:

```bash
python main.py
```
