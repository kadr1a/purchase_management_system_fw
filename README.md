# Система управления закупками

## Назначение

Учебное приложение для первичной проверки заявки на закупку: расчёта её предварительной стоимости, проверки бюджета и определения текущего результата проверки. На этапе ПР1 программа работает в консольном режиме и демонстрирует базовый сценарий закупочной деятельности.

## Целевая аудитория

Сотрудники организации, которые формируют заявки на приобретение товаров и предварительно оценивают расходы.

## Предметная область

Организация и сопровождение закупочной деятельности. Сотрудник указывает товар, его цену и необходимое количество, после чего система рассчитывает сумму заявки и проверяет, укладывается ли закупка в установленный бюджет.

## Основные сущности

- **Заявка** — обращение на закупку товара с указанием количества и статуса.
- **Товар** — позиция для закупки с наименованием и ценой.
- **Поставщик** — организация или лицо, у которого планируется закупка.
- **Заказ** — оформленная закупка у выбранного поставщика с итоговой стоимостью и статусом.

## Основные функции

- Расчёт предварительной стоимости заявки на основании цены товара и количества.
- Проверка корректности введённых цены, количества и бюджета.
- Проверка, укладывается ли сумма заявки в доступный бюджет, и определение результата предварительного согласования.

## Запуск

Требуется Python 3.10 или новее. Сторонние библиотеки не используются.

```bash
python main.py
```

В Windows при необходимости используйте команду `py main.py`.

## Отладка

Для выполнения задания по отладке откройте папку проекта в IDE (например, VS Code или PyCharm), поставьте breakpoint на строке вызова `check_budget(...)` в `main.py` и запустите программу через Debug. Выполняйте код пошагово и проследите значения `unit_price`, `quantity`, `budget` и `total`.

Чтобы выполнить проверку с ошибочным результатом, временно замените в `utils.py` оператор умножения `*` на сложение `+` в функции `calculate_total`. Запустите программу в режиме отладки, сравните ожидаемую сумму с фактической и найдите причину. После проверки обязательно верните оператор `*`.
